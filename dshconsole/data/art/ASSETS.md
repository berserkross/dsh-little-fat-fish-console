# DSH Console - original mascot art

All artwork in this directory is drawn from scratch for this project. No reference
image, no traced artwork, no generative image model was used: every file started as
hand-authored SVG markup in `src/` and was rasterised with headless Chrome by
`scripts/render-art.py`. The character is an original chibi blue-whale girl
(headphones as whale ear-cups, whale-tail hair clip, cyan scarf, chest wave mark).

## Regenerate everything

```
python scripts/render-art.py            # renders all five PNGs + _preview/_zoom32
python scripts/render-art.py --verify   # same, then prints the alpha/geometry table
```

The script needs Python 3 + Pillow (already vendored in this repo's toolchain, no new
pip dependency) and a local Chrome or Edge (auto-detected: `C:\Program Files\Google\Chrome\Application\chrome.exe`
then the x86/Edge fallbacks, or pass `--chrome PATH`). Each SVG is wrapped in a
transparent HTML page and rasterised with
`--headless=new --default-background-color=00000000 --window-size=N,N --screenshot=...`,
which yields exactly N x N with true alpha (no white matte).

Reproducibility: deleting the PNGs and re-running the script reproduces all seven
files **byte for byte** (pixel difference 0 on every file, checked with Pillow
`ImageChops.difference`).

## Notes for consumers

- Every PNG is RGBA with a real alpha channel; all four corners are fully transparent,
  so the files can sit on any panel colour without a matte box.
- `mascot_logo@32.png` is its own simplified drawing (silhouette + two eyes + cyan pips),
  not a scaled-down `@72` icon: line weights and details were dropped on purpose so the
  mark survives a 32 px slot. `_zoom32.png` shows it at 6x.
- The images are UI icons, not photographs: prefer integer scaling (CSS `width` equal to
  the file's pixel size, or a multiple of it) to keep the 1.5-2.2 px outlines crisp.
